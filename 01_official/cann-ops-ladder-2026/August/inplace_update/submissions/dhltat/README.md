# inplace_update

2026 年 CANN 算子天梯赛 August 参赛工程。GitCode 提交账号：`dhltat`。

## 来源

取自 那么多痛苦的昨天 对应月份的最后一次评测提交 [158002](https://cannjudge.cn/public/ladder_august/inplace_update/submission/6a8bba2382cffa8f16d8bc10)，10/10 个测试点通过。Host 与 Kernel 源码保持原评测版本。

## 结构

`op_host/` 包含注册、shape 与 tiling；`op_kernel/` 包含 Device 实现。工程附带构建配置、调用示例和平台测试文件，按仓库投稿规范保存。
