# 🏆 2026 CANN 算子天梯赛 

> **大赛简介**
> CANN 算子天梯赛，是面向全社会 AI 算子工程师的长期算子性能极限挑战赛，基于昇腾平台对算子进行长期优化打榜，按月度结算奖励性能榜首，为每一位算子开发者提供绝佳的实践平台。

>天梯赛的算子题目来源于真实的场景需求，目的是让参赛者持续优化的算子可以合入CANN算子库并在真实场景发挥作用。因此天梯赛算子禁止只针对特定shape进行编程，需要参赛者实现泛化的算子以满足实际场景不同算子规格的要求。

## ⚖️ 赛事规则

* 🎯 **参赛对象要求**：面向全社会开发者。
* 📝 **参赛答题要求**：参赛选手需要根据赛题赛规要求，在指定时间内完成报名、组队、作品提交，方为有效参赛。(每天最大提交次数为50次，取最优成绩为最后成绩记录)
* 🤝 **组队要求**：先报名后组队，每支队伍 1-3 人。
* 🛡️ **公平参赛**：每个阶段比赛结束后，大赛组委会将进行代码查验。如发现代码重复或违规等情况，将直接取消该队伍参赛资格和现有成绩。
* ⚔️ **比赛机制**：
  1.  天梯赛长期举办，每月最后一天下午5:00结算当月排名，每个算子题目独立评选一个月度冠军，在此之后的提交不计入当月成绩
  2.  新赛题每题首月性能最佳提交成为月度冠军并获奖
  3.  跨月赛题当月性能最佳提交且超过历史最佳提交性能3%以上成为月度冠军获奖，计算方式为所有测试用例耗时总和提升比例大于3%。
  4.  每个算子独立评选月度冠军，需满足精度达标且性能符合上述要求
  5.  每一道赛题连续两个月获奖者不可以是同一人
  6.  算子要求具备泛化性，满足赛题中的shape范围，禁止只针对测试用例shape进行编程
  7.  比赛每月封榜后会对算子进行泛化性验收测试，通过验收阶段才给予奖励。
  8.  每月单人最多获奖三道赛题，优先奖金级别最高的三道题。
