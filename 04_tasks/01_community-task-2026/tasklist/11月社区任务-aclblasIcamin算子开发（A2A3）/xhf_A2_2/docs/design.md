# 需求背景

11月社区任务要求在 Atlas A2/A3 上实现 `aclblasIcamin`。该接口查找单精度复数向量中 BLAS 模值最小元素的首个位置。ops-blas 公共头文件已有接口声明，主线实现覆盖 950 系列。本设计补齐 arch22。

任务书和配套用例见[昇腾社区任务页](https://www.hiascend.com/activities/task-center/details/6ff54aa152cf4edbbaf516fa36024893)。

# 需求分析

```cpp
aclblasStatus_t aclblasIcamin(
    aclblasHandle_t handle, int n, const aclblasComplex* x, int incx, int* result);
```

对每个逻辑下标 i（从 0 开始），读取设备向量 `x[i * incx]`，以 FP32 计算 `abs(real) + abs(imag)`。输出设备 INT32 值为最小模值对应的最小逻辑下标加 1。首元素模值为 NaN 时返回 1，后续 NaN 不满足严格小于条件。支持无穷、正负零和相等模值。

| 条件 | 接口行为 |
| --- | --- |
| handle 为空 | 返回 HANDLE_IS_NULLPTR |
| n 为负或 result 为空 | 返回 INVALID_VALUE |
| n 为零或 incx 小于 1 | 在绑定流上写入 0，此时允许 x 为空 |
| 正常计算且 x 为空，或末元素复数偏移超过 INT32_MAX | 返回 INVALID_VALUE |
| 其余参数 | 在绑定流上计算，由调用者同步流并读取结果 |

# 详细设计

## Host 侧

按参数表顺序校验。正常路径以 64 位计算 `(n - 1) * incx`。快速返回使用绑定流上的异步清零操作。计算路径读取 AIV 核数，按输入规模决定实际分核数，小输入用单核处理。向 kernel 传递长度和步长。多核路径使用句柄 workspace，每核占一个 32 B 对齐槽保存模值和 INT32 下标，下发前检查可用大小。调用返回前无需同步流。

## Kernel 侧

各 AIV 处理互不重叠的连续逻辑下标区间，区间起点尽量按 32 B 对齐并覆盖尾部。设备索引转成实虚分量偏移时保持 64 位。

- 连续输入批量搬入 UB。对交错分量做绝对值，以奇偶掩码分离实虚部，相加生成模值。向量比较把 NaN 映射到正无穷，再归约取模值及其首个下标。尾部按有效长度搬运，归约补位填正无穷。连续大向量用双缓冲重叠搬运和计算。
- 小输入与正步长非连续输入按实际有效逻辑元素扫描。核内、核间均按模值优先、下标次之合并。模值比较不依赖 FP32 表示整数下标。
- 多核各自发布候选并同步后，核 0 合并并写出 4 字节结果。单核直接写出。首元素为 NaN 或所有候选均为正无穷时返回 1。

沿用公共签名和现有 950 实现。新增 arch22 实现位于 `blas/iamin/arch22/`。

# 可维可测分析

| 项目 | 自验证方法 |
| --- | --- |
| 标准入口 | CANN 9.1.0 下构建 `icamin`，在 arch22 注册 `icamin_test`，默认发现原 CSV 和补充用例 |
| 精度 | 1000 条原用例逐例与顺序 CPU 参考做 INT32 精确比较，补充正态分布、NaN、跨核相等模值、偏移对齐和空句柄 |
| 性能 | 独占 910B3，逐例采集 200 条原性能用例的 `msprof op` Task Duration，排除 5 次预热，至少 10 次有效采样取均值，逐例校验 GPU/NPU ≥ 0.8 |
| 流与边界 | 在绑定流上连续下发并检查结果和输出哨兵。负向用例用单元素占位并检查状态码 |
| 交付 | 归档逐例日志、GPU/NPU 明细、原始采样和构建身份，按任务书模板整理自验证材料 |

用实测 Task Duration 调整分核与 tile 大小。A2 自验证结果与设备、CANN 版本及源码提交关联。
