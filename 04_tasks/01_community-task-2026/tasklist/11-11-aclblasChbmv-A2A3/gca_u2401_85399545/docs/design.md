# 需求背景（required）

## 需求来源

对应社区任务“11月社区任务-aclblasChbmv算子开发（A2A3）”，为 [ops-blas](https://gitcode.com/cann/ops-blas) 补充单精度复数 Hermitian 带状矩阵与向量乘接口 `aclblasChbmv`。

## 背景介绍

在 `blas/sbmv/arch22/` 同族工程中新增 Host 参数检查、tiling 和 Ascend C kernel，在公共头文件增加接口声明，并在 `test/sbmv/chbmv/arch22/` 增加 CSV 驱动 GTest。带状格式仅存储一侧三角，计算时使用 Hermitian 共轭对称性恢复另一侧，不展开为稠密矩阵。

输入输出为 COMPLEX64，实部、虚部分别以 FLOAT32 表示。A、x 位于 Device，y 在 Device 原地更新；alpha、beta 为 Host 复数标量。

# 需求分析（required）

## 需求描述

实现 `y = alpha * A * x + beta * y`，支持 UPPER/LOWER 列主序带状存储、前导维 padding、正负向量步长、有效带宽裁剪、零维快速返回和任务书规定的异常返回码。对角虚部忽略，beta=0 不读 y 旧值，通过 handle 绑定的 stream 异步执行。

## 需求拆解

1. 新增共用公开接口，保持 `cublasChbmv` 参数顺序和仓内 BLAS 类型风格。
2. Host 完成有序校验、原始及有效带宽计算、分核和路径选择。
3. kernel 按窄带对角线、连续宽带面板、通用步长行归约三条路径执行，输出先放 UB，再精确 DMA 提交。
4. 对实际计算中出现的非有限中间结果，以及范围异常的有限标量，增加设备内有限值高精度重算；被引用输入含 NaN/Inf 时保留专门的特殊值处理。
5. 使用 Netlib BLAS 3.10.0 的 FP64 HBMV 结果验证实部和虚部，覆盖原始、分布和边界补充场景，按任务书采集正式性能。

# 详细设计（required）

## 算子分析

### 数学公式

令 `κ = min(k, n-1)`，以下下标从 0 开始：

`z[i] = Σ A[i,j] * x[j]`，其中 `max(0,i-κ) ≤ j ≤ min(n-1,i+κ)`。

`y_new[i] = alpha * z[i] + beta * y_old[i]`。

带状数组 AB 的物理偏移如下，`conj` 表示复数共轭：

| 存储模式 | 元素位置 | 读取的值 |
| --- | --- | --- |
| UPPER | j ≥ i | `AB[k+i-j + j*lda]` |
| UPPER | j < i | `conj(AB[k+j-i + i*lda])` |
| LOWER | j ≤ i | `AB[i-j + j*lda]` |
| LOWER | j > i | `conj(AB[j-i + i*lda])` |

仅对有效带内元素使用上表。对角项单独计算 `real(AB[diag]) * x[i]`，避免把被忽略的对角虚部作为复乘操作数。`k > n-1` 时只裁剪求和范围；UPPER 对角仍位于物理行 k，不用 κ 替换。

### 支持数据类型

alpha、beta、A、x、y 均为 `aclblasComplex`，实部和虚部各为 FLOAT32。公开输入输出 dtype 保持 COMPLEX64。

### 支持形状

| 参数 | 支持范围 |
| --- | --- |
| n、k | int32；n ≥ 0、k ≥ 0；k 可大于 n-1 |
| A | 列主序 `lda × n` 个复数元素，`lda ≥ k+1` |
| x、y | 逻辑长度 n；物理长度至少 `1+(n-1)*abs(inc)` |
| incx、incy | 非零且非 INT32_MIN；向量跨度在 int32 可表示范围内 |

n=0 无计算。不涉及广播、额外非连续视图或输出视图。

## 算子实现

### 实现方案

#### 3.2.1 host侧设计：

在公共头文件中增加同一接口，不增加平行 API：

```cpp
aclblasStatus_t aclblasChbmv(
    aclblasHandle_t handle, aclblasFillMode_t uplo,
    int n, int k, const aclblasComplex* alpha,
    const aclblasComplex* A, int lda,
    const aclblasComplex* x, int incx,
    const aclblasComplex* beta, aclblasComplex* y, int incy);
```

校验顺序为 handle 判空、n<0 拒绝、n=0 返回成功，随后检查 uplo、k、lda、步长和全部必需指针。非法 uplo 按本任务返回 `ACLBLAS_STATUS_INVALID_VALUE`。`k+1`、步长绝对值和跨度乘积先提升为 int64，避免整数回绕。完成指针校验后才读取 Host 标量，beta=0 仍要求 y 非空。

alpha=(0,0)、beta=(1,0) 在校验后可直接返回；其他 alpha=0 场景计算 beta*y。Host 不读取 Device A/x/y 内容，不依据测试用例身份选择路径。

##### 1. 分核策略：

窄带对角线路径保留128行物理缓冲，按矩阵几何选择逻辑输出块：`n≤64 且 2κ≥n` 时为8行，否则 `n≤256` 为32行、`n≤512` 为64行，其余为128行。核数为 `min(AIV核数, ceil(n/逻辑块行数))`，各核循环处理所属逻辑块。通用行归约仍使用64行所有权块。

连续宽带路径将 `ceil(n/4)` 个四复数元素组连续均分给 `min(AIV核数, ceil(n/4))` 个核，每组对应32字节输出，只有全矩阵最后一组可能不足四行。每核在其连续区间内处理最多32行的面板，避免固定64行循环分配造成部分核承担两轮。每行仅由一个核负责，不使用跨核原子累加或全局结果工作区。

当前对 `incy != 1` 或 y 基址未按 32 字节对齐的情况采用单核输出策略。连续、对齐输出保留多核。所有路径均通过 UB 暂存后 DMA 写回，避免标量 GM 缓存行写回覆盖相邻输出。

##### 2. 数据分块和内存优化策略：

首先选择窄带路径：`incx=incy=1`、`κ≤64`，且 `(128+2κ)*lda*8 ≤ 144 KiB`。批量搬入合法物理窗口，Gather 只选择有效带内元素；padding 和无对应矩阵元素的槽位不参与乘加。索引平面使用向量指令初始化，以减少每核标量索引开销。

若不满足窄带门槛，连续向量、`κ≥64`、`lda>64`、DMA stride 可表示且标量有限时，可选择宽带面板路径。面板最多包含32个输出行、每段64个输入列，直接存储段和镜像段分别搬运；共享矩形、中心三角及边缘使用向量复乘和行归约。中心三角通过索引恢复共轭关系。边缘及中心非对角区域按整面板构造有效位掩码，在乘法前分别将无效位置的 A 实部、A 虚部、x 实部、x 虚部 Select 为零，随后复用矩形乘加及归约；有效列之外仍由原列掩码阻止计算。实对角单独计算。

其余情况使用通用行归约路径，每段最多处理 256 个有效项，支持正负 incx/incy 与 lda padding。超过 DMA stride 字段范围时使用标量读取回退，地址运算保持 int64。负步长通过逻辑索引到物理 span 的映射定位。

| 路径 | 源码声明的 UB 缓冲预算 | 写回方式 |
| --- | --- | --- |
| 窄带对角线（物理128行，逻辑8/32/64/128行） | A窗口147456 B；x窗口2048 B；计算平面5120 B；I/O1024 B；索引3072 B；合计158720 B | 有效行交错打包，整块 DMA |
| 通用行归约 | A/x搬运16384 B；计算平面12288 B；索引2048 B；输出512 B；合计31232 B | 连续输出每64行 DMA；其他步长精确8 B DMA |
| 32×64宽带面板及其行回退 | 面板、索引、位掩码及持久差值平面108672 B；行回退31232 B；组合139904 B | 正常面板整块 DMA；部分回退仅提交其余有效行 |

以上为互斥路径的显式 `InitBuffer` 预算，最大为158720 B，不代表编译器隐式资源或设备峰值。三条路径均不生成 n×n 稠密矩阵；临时缓冲随分块大小固定。

##### 3. tilingkey规划策略：

采用单一 kernel 入口。tiling 的 path 区分对角线与通用行路径；在后者分支内依据连续步长、带宽、lda、stride 和标量条件进一步选择宽带面板。不使用图模式 TilingKey 注册。

tiling 携带 n、原始 k、有效 κ、lda、uplo、核数、int64 步长以及复数标量。原始 k 用于物理带状索引，有效 κ 用于逻辑范围裁剪。

#### 3.2.2 kernel侧设计：

**窄带对角线路径。** 每次按 Host 同一规则处理8、32、64或128个逻辑行，物理缓冲及打包索引仍保留128行容量。初始化实虚累加平面，遍历 `d=-κ…κ` 的有效对角偏移。Gather 对应 AB/x，镜像侧虚部变号，使用向量融合乘加累积；对角仅做实数乘复向量。应用 alpha 和 beta 后交错打包，通过 DMA 写回有效行。尾块只处理有效元素。

**连续宽带面板路径。** 各核在以四复数元素组均分的连续所有权区间内处理最多32行面板，共同的左右带内矩形按64列搬运。中心三角用预计算索引和共轭掩码恢复行视图。对中心非对角区和边缘，以行列差构造整面板有效位掩码，分别清零无效位置的四个实数操作数，再按原顺序执行复乘、逐行归约和累加。仅清零 A 不能避免 `0*Inf`，因此 x 的实虚分量也一并清零。有效元素及有效列掩码保持原值；对角仅用实部单独补齐。输出先放面板 UB，正常情况一次 DMA；已通过特殊值回退写出的行不会被面板再次覆盖。

**通用步长行路径。** 每行分为对角、左非对角段和右非对角段，按最多256项拆出实虚平面并归约。ComputeRow 只写 UB 输出块；连续 y 每64行提交，非连续 y 按逻辑映射使用精确8 B DMA，保留步长间隙及保护区。

**异常有限值重算。** 直接 FLOAT32 乘加可能在最终结果可表示时先发生中间溢出。kernel 在提交 y 前检查实际行结果；若出现非有限值，或有限非零 alpha/beta 分量大于 `2^16`、小于 `2^-16`，尝试设备内有限值重算。该路径以整数实现53位尾数、指数和舍入，按 Netlib ZHBMV 的列更新顺序重放目标行，并在最后收窄为 FLOAT32。UPPER 保持本列对角及左侧 temp2 累加后，再接受后续列散射；LOWER 保持前列散射、本列对角、右侧 temp2 的顺序。它不要求硬件原生 FP64。

重算先处理 beta*y：beta=0 不读旧 y，beta=1 直接使用旧分量；alpha=0 随后返回。对角只读取实部。若被引用输入含 NaN/Inf，有限值重算不提交结果，保留特殊值计算路径。所有重算发生在该行第一次 GM 输出前，使用原始旧 y。该数据驱动筛选不替代全量精度验证，未触发重算的有限结果也按同一标准验收。

各路径在搬运、向量计算、标量读取与 DMA 写回之间设置流水事件和向量屏障。窄带在 FoldBeta 后完成 V→S 检查，再以 S→V 交错打包；输出暂存通过 S→MTE3 提交，并等待 MTE3→S/V/MTE2 后复用。部分面板的完成标记避免覆写已提交的回退行。

每行仅遍历有效带宽，算术复杂度为 `O(n*(κ+1))`，满带退化为 `O(n²)`。路径门槛、额外搬运和数值重算的性能效果以正式测量为准。

## 算子约束限制

| 约束 | 实现处理 |
| --- | --- |
| 指定三角及Hermitian语义 | 只计算有效带内元素，镜像侧取共轭，对角虚部忽略 |
| 正负步长与lda padding | int64地址映射，原始k和有效κ分别保留 |
| 零维及异常返回 | handle最优先，随后n校验和quick return，其余非法参数按任务规定返回 |
| beta=0与原地输出 | 不读旧y；y仍须有效非空；每行旧值在第一次输出提交前读取 |
| 异步执行 | 使用handle stream，读回结果前同步 |
| 特殊值与确定性 | 按任务书非有限值规则验证，不要求归约顺序跨实现逐位一致 |
| 范围 | 限于公开接口的lda/incx/incy，不扩展额外视图、广播或其他dtype |

| 项目 | 标准与验证方法 | 来源 |

| 内存 | 无独立内存验收指标，按任务模板说明不涉及 | 任务书§3.4 |

非有限值按任务书处理：双方同为NaN、同号Inf或NaN与Inf等效，有限与非有限不等效。非有限元素独立统计，不进入有限误差统计，且应全部满足等效规则。

性能用例使用固定A/x/alpha/beta，beta固定为零，重复调用不依赖旧y。功能比对、预热和有效采样分别记录。aclrtEvent均值作为辅助信息，与正式msprof数据分别保留。

**当前验证状态：**已对窄带自适应分块、连续宽带均分及面板掩码方案完成代表性精度和正式性能定向验证。当前完整源码已完成CANN 9.1.0构建，2529项功能回归及200项msprof正式性能验证仍在进行，结果将与同一源码、库、测试程序和输入身份绑定后提供，不能将组件定向结果拼成全量通过。测试注册范围包括2294项NPU CSV数值场景、190项Host恒等返回并核对输出、16项零维无写入检查、25项异常返回及保护检查，另有4项定向UT。Host与负例检查不计作NPU数值调用；辅助事件计时不替代正式msprof Task Duration。
