# 面向零基础的 PyPTO 算子开发课程设计

## 1. 需求背景

### 1.1 需求来源

本设计对应[11 月社区任务：开发一套面向 0 基础人群的 PyPTO 算子开发课程](https://www.hiascend.com/activities/task-center/details/1073bd69ad9f48f7848f2d940a5b2918?menu=guide)。任务书要求以 Jupyter Notebook 为载体，从数学基础讲到神经网络与 Transformer，课程涉及的算子使用 PyPTO 实现，并在至少一个 CANNLab 环境运行验证。

课程计划提交到 `cann/cann-learning-hub` 的 `contrib/tutorials/pypto_zero_to_transformer/`；[课程代码 PR](https://gitcode.com/cann/cann-learning-hub/pull/1451)与本文档分别评审。本 PR 仅提交课程设计文档。

### 1.2 目标读者与学习目标

读者仅需了解 Python 变量、函数、循环和列表，可以没有人工智能、线性代数、微积分及 C/C++ 基础。课程面向学生、软件开发和测试工程师及希望入门 AI 的其他学习者。

学完后，学习者应能：

1. 解释标量、向量、矩阵、张量、梯度、损失和概率等概念，并写出简单计算的形状与数学含义。
2. 使用 PyPTO 编写和调用简单 Kernel，理解输入输出、数据类型、分块以及独立结果检查的作用。
3. 读懂 MLP、CNN、RNN 和 Transformer 的主要结构，动手运行小规模计算和课程提供的训练示例。
4. 在配套 CANNLab 环境中运行 Notebook，依据参考结果排查代码和环境问题。

## 2. 需求分析

### 2.1 交付范围

交付物包括课程及章节 README、按小节组织的 Notebook、正文源码、学生模板、参考答案、配图、覆盖表和验证说明。章节首先给出概述，最后给出综合实践；中间小节包括概述、讲解、可执行示例和练习。

课程设计为 7 章、58 本 Notebook：7 本章节概述、44 本教学小节和 7 本章节实践。教学小节配有独立编程练习及答案；每章综合实践包含客观题和简单、中等、困难三道编程题，共 21 道章节编程题。课程配有 58 份自绘 SVG 示意图。

### 2.2 能力递进与考核

| 阶段 | 章节 | 能力目标 | 主要考核方式 |
| --- | --- | --- | --- |
| 初级 | 01—03 | 建立 AI 和张量概念，编写并核对基本 PyPTO 计算 | 知识题、基础 Kernel 与梯度检查 |
| 中级 | 04—05 | 理解前向、反向和参数更新，解释卷积网络的数据流 | MLP 训练、卷积和池化实践 |
| 高级入门 | 06—07 | 理解序列状态、注意力和 Transformer 组件 | RNN 状态与梯度、注意力和小型解码器实践 |

“高级入门”表示本课程内的能力层级，不代表完整大模型训练或生产级算子性能优化能力。各阶段以对应小节练习和章节实践考查，不以运行无报错替代理解。

## 3. 详细设计

### 3.1 章节与知识点

| 章节 | Notebook 数 | 主要内容 | 阶段产出 |
| --- | ---: | --- | --- |
| 01 从 AI 到第一个 PyPTO 算子 | 7 | 环境、Notebook、AI 基本术语、Kernel、shape、dtype、分块与结果检查 | 编写并运行第一个 PyPTO Kernel |
| 02 线性代数 | 7 | 标量、向量、矩阵、张量、广播、重塑、转置、归约、点积与矩阵乘 | 描述张量形状和矩阵乘的维度约束 |
| 03 微积分与概率 | 8 | 导数、偏导、梯度、链式法则、梯度下降、概率、稳定 Softmax 与有限差分 | 推导简单梯度并用独立差分核对 |
| 04 神经网络 | 9 | 数据与线性回归、激活函数、MLP、前向与反向、SGD、权重衰减、Dropout、容量与初始化 | 运行小型分类训练并核对参数梯度 |
| 05 CNN | 8 | 局部连接、权重共享、卷积、填充、步幅、通道、池化及经典结构 | 核对卷积、池化、残差和稠密连接示例 |
| 06 RNN | 9 | 序列、文本、语言模型、RNN、BPTT、梯度消失/爆炸、GRU、LSTM、深层与双向 RNN、Seq2Seq | 核对循环状态和反向梯度 |
| 07 Transformer | 10 | 词元嵌入、位置、Q/K/V、缩放点积、多头、掩码、残差、LayerNorm、FFN、编码器/解码器、语言训练与生成 | 运行小型解码器、输出头训练及生成示例 |

| 注意力、Transformer 组成、语言任务与生成 | 07.02—07.09 | 逐步组合嵌入、位置、注意力、子层、输出头和自回归生成 |

学习者从课程 README 进入章节。每个教学小节先解释新概念，再结合示意图、代码和结果观察讲解；正文与练习使用各自的输入和参考实现。Notebook 使用 `%%writefile` 等单元操作生成本节工作文件，并自动定位课程根目录，不要求学习者手动切换目录。学生模板默认不在“运行全部”时调用未完成的函数；答案可独立查看和执行。

### 3.3 PyPTO 实现与教学边界

`common/ops.py` 提供逐元素计算、归约、矩阵乘、Softmax、卷积、池化、循环单元与注意力等教学原语，`common/models.py` 组合模型，`common/reference.py` 提供独立参考。课程使用 PyPTO Tensor API 和 `@pypto.frontend.jit` 构建 Kernel，运行入口显式选择 `RunMode.NPU`；向量及矩阵计算按示例设置相应 tile。NumPy 用于数据构造与独立参考，PyTorch/TorchNPU 用于张量和设备交互，CPU autograd 用于部分梯度参考，Host 负责训练轮次、时间步和词元选择等控制。

示例优先服务于学习与结果核对，使用课程指定的小规模静态 shape、FP32 和连续数据；不将其声称为通用高性能算子。卷积采用可读的切片与乘加，嵌入使用小词表 one-hot 矩阵乘。CNN 示例展示关键连接关系，不声称完整复现经典网络训练；MLP 和 RNN 包含解析反向，Transformer 的小型语言训练示例冻结骨干、只更新输出头。KV Cache 练习核对注意力核心等价性，主生成路径重算前缀。

### 3.4 运行环境

课程目标硬件为 Atlas A2/A3，推荐 CANN 9.1.0。已观察的 CANNLab 实例为 A2 / 910B3、CANN 9.1.0、PyPTO 0.2.1、Python 3.11.4，Torch/TorchNPU 包版本为 2.7.1+cpu / 2.7.1.post4。

该实例页面显示的镜像模板名为 `cann_9.0.0 py3.11-A2-arm-20260921`，与实例内实际安装的 CANN 9.1.0 分别记录。以上结果只对应实际使用的实例；新建同名模板实例的复现与 A3 尚未验证。课程依赖以环境预装的兼容版本为准；维护者需要的 Notebook 执行依赖放在课程私有环境，不要求更改全局 CANN/PyPTO。

## 4. 可维可测分析

### 4.1 正确性与覆盖

1. 按清单逐本使用新内核运行 Notebook，正文示例和参考答案均执行；任一单元报错即停止并记录首败。
2. 输出与独立 NumPy 或 CPU autograd 参考比较，课程示例默认 FP32 `atol=rtol=1e-4`，多阶段模型或有限差分按对应代码预先声明的合同检查；不得因失败临时放宽容差。以上为课程示例范围，不代表 PyPTO 的通用精度标准。
3. 检查章节目录、Notebook 结构、源码语法、练习与答案、配图和本地链接，并保持提交的 Notebook 输出与执行计数为空。
4. NPU 执行前核对设备映射、健康和占用，使用环境中共同约定的设备锁串行运行；中断批次的状态和首败保留，续跑结果按清单合并，不覆盖旧记录。

代表性检查包括：

| 检查内容 | 输入或场景 | 预期 |
| --- | --- | --- |
| 基础张量与矩阵运算 | 课程给定的逐元素、广播、归约和矩阵乘输入 | 输出形状及数值与独立参考一致 |
| 卷积和池化 | 教学用多通道、填充和步幅示例 | 输出形状及全部输出数值符合参考 |
| MLP 和 RNN | 前向、参数梯度及状态递推示例 | 与独立参考逐项比较，并检查梯度 |
| 注意力和 Transformer | 掩码、编码器/解码器、生成及缓存练习 | 核对输出及掩码约束；按实际练习范围检查缓存等价性 |
| 课程运行 | 从课程目录或工作区启动，逐本新内核执行 | 全部选中 Notebook 的代码单元执行结束且无错误 |

维护者在已配置的配套环境中可使用 `python tools/run_notebooks.py --run-id <本次名称> --lock <共同设备锁>` 逐本运行；实际锁路径应依据当次设备映射填写，可重复传入多个 `--lock`。此命令面向维护者，学习者仍通过 Notebook 单元完成课程操作。

## 5. 兼容性与风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 镜像模板名称和实例实际软件版本不同 | 学习者可能无法复现验证环境 | 分别记录模板名和实际版本，复查新建实例 |
| PyPTO/CANN API 随版本变化 | Kernel 编译或运行失败 | 记录 API 来源和版本，遇不兼容先定位接口并重跑受影响范围 |
| 课程示例被误解为完整模型或性能基准 | 对学习成果和性能产生错误预期 | 明确小规模教学模型、训练范围和适用 shape/dtype |
| 正文与练习相互依赖 | 跳过正文后练习无法复现 | 使用独立输入、学生模板和参考答案，逐本新内核检查 |
| 在线入口未配置 | 仓库在线体验尚不能确认 | 保留待配置状态，由维护者配置后验证 |
