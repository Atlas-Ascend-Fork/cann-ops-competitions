### 1.2 课程定位与受众

PyPTO 是昇腾生态的算子编程框架（Tensor 编程 + `pypto.frontend.jit` 即时编译，CANN 9.1.0 起随包集成，见 pypto.gitcode.com 官方文档）。本课程默认学习者**无 AI 基础**（仅要求基础 Python），从数学基础一路建到 Transformer；学习路径上的每个数学/网络算子都用 PyPTO 实现、运行、验证——学完能理解神经网络原理，并形成"用 PyPTO 写算子"的肌肉记忆。

受众：学生、软件开发/测试工程师及其他行业从业者。

### 2.3 需求拆解

1. **课程骨架**：7 章 ×（概述 + 教学节 ×N + 章节实践），共 51 个 notebook + 每章 README + 主 README。

### 3.2 PyPTO 计算设计

**编程模型**（依据 pypto.gitcode.com 官方文档 Tensor/JIT 接口）：

```python
import pypto
from pypto.frontend import jit

@jit
def add_kernel(x, y, out):        # 设备侧：带类型注解的张量计算
    out = x + y                   # 教学示例以真实 API 校准后定稿

x, y, out = host_tensors(...)     # 主机准备输入/输出（torch_npu 承载）
add_kernel(x, y, out)             # 即时编译执行
pypto.sync()                      # 同步后读回
```

课程代码以 CANNLab 实际安装版本的 API 为准逐个校准后定稿；开发期先在 A2 CANNLab 环境跑通全部模板 notebook（环境自检 → add → matmul → conv → attention 五级样例），再批量生产章节内容——**API 以实测定，不以文档记忆定**（官方文档可能含更新版本能力，与已装版本差异在课程中显式说明）。

**算子实现约定**：

- 每个教学算子 = PyPTO 设备实现 + 独立参考实现（NumPy/torch CPU）+ 对照验证函数（atol/rtol 逐算子配置，FP32 优先）；
- 数值稳定性显式教学：softmax 减最大值、log-sum-exp、LayerNorm 的 epsilon、（如涉及）FP16 输入 FP32 累加的误差来源讲解；
- 随机性全部显式种子（练习可复现）；Dropout 掩码固定种子生成，训练缩放/推理直通分开演示。

### 4.2 数值验证口径

- 每算子对照：`abs(actual − ref) ≤ atol + rtol·abs(ref)`（FP32 默认 atol=1e-5, rtol=1e-4；训练类用例另验损失单调趋势与有限梯度）；
- 特殊行为显式教学处（softmax 大值、梯度饱和区、掩码全遮蔽行）单独设判据用例；
- 因果性：修改未来 token，断言前缀输出不变（第 7 章固定实验）。
