# 需求分析（required）

## 需求描述

计算 `y = alpha * op(A) * x + beta * y`。m/n 始终是原矩阵 A 的形状。
支持 N/T/C、上下非对称带宽、lda padding、正负非零步长、空维度和特殊复数值。
返回值采用公共 aclblasStatus_t；由 handle 绑定 stream，接口保持异步。

## 需求拆解

1. 复用公共头文件已有的 aclblasCgbmv 签名；arch22 Host 负责校验和按值 tiling 下发。
2. AIV SIMD 实现复数乘法、带内访问和输出规约；A2/A3 使用 arch22 代码，产品验证状态单独记录。
3. GTest 注册原始 CSV 与补充 CSV，CBLAS 生成 golden。
4. 原始 GPU 基线保留，性能采集和报告工具严格区分待测与通过。

# 详细设计（required）

## 算子分析

### 数学公式

零基下 `A(i,j)` 的带状地址是 `j*lda + ku+i-j`。
N 模式输出 i 的输入范围为 `[max(0,i-kl), min(n,i+ku+1))`，
A 相邻系数的复数元素步距为 lda-1。
T/C 模式输出 j 的输入范围为 `[max(0,j-ku), min(m,j+kl+1))`，
A 在该列内连续；C 模式对虚部取负。
对于步长 s<0，向量起始偏移为 `(length-1)*(-s)`，逻辑元素 k 位于 start+k*s。

### 支持数据类型及形状

输入/输出为 COMPLEX64，使用 FP32 算术，无降精度转换。
尺寸和步长为 int API；地址计算、带宽和跨度校验使用 int64_t。
运行时 m/n/带宽决定遍历范围，不依赖测试 shape 白名单。

## 算子实现

### Host 校验和异步调用

校验顺序：空 handle；非法枚举/负维度/负带宽/零步长/不足 lda/空标量；
带宽上界；空维 no-op；alpha=0,beta=1 no-op；参与计算的指针；地址跨度。
零维与带宽上界的矛盾按 `kl <= max(m-1,0)`、`ku <= max(n-1,0)` 处理。
非法枚举返回 INVALID_VALUE。beta=0 只免除原 y 输入读取，不免除输出指针要求。
alpha/beta 是 Host 标量，只复制数值；A/x/y 生命周期由调用者保持到 stream 完成。
主机不申请/释放临时设备内存，不复制 tiling 到独立 GM，不同步 stream。

### Host 分派与分核

`cgbmv_host.cpp` 初始 block 数为 `min(AIV 核数, 输出元素数)`。
`cgbmv_dispatch.h` 依据 trans、m/n、kl/ku、lda、incx/incy、alpha/beta
和设备核数选择实现；不读取用例名、golden、GPU 耗时或 profiler 状态。
N 模式非零前缀长度为 `min(m,n+kl)`，T/C 为 `min(n,m+ku)`。
R32 的实际 launch block 数还按有效 row tile 数裁剪，零尾仍完整写回。

Host 的几何成本比较考虑最忙核的搬运块数、补齐计算量、有效计算量与 tile
数；这些是选择实现的估计，不是性能达标证明。每个输出由单核完成，
没有跨核浮点原子累加和跨核结果归约。

| 路径组 | 组织方式 | 保留原因与边界 |
| --- | --- | --- |
| General、对角、窄带 | 通用参数与窄带入口；对角和长零尾有独立入口 | 保留非单位步长、一般 alpha/beta、极端跨度等语义 |
| 短 N | ordered/panel 与单 strip 入口 | 减少短输入初始化与搬运成本；保留既定求和边界 |
| 中宽带 N | C64/C128，R16/R32/R48 等 row tile | 复用列方向 A/x 搬运；按有效几何选择 tile |
| R64/R96 | 双槽输入、packed complex 运算与按需有序重算 | 兼顾搬运描述符数量、占用和精度 |
| R128 宽带 | C32/R128，两个 64 行向量区间 | 摊薄每列搬运，并保留递增列次序的累加 |
| T/C | 连续列访问、结构化面板及宽带独立入口 | 共轭模式改变虚部符号，避免干扰已验证 N 路径 |

R128 的公开几何条件还要求有效行数大于 `64*blocks` 且不超过
`128*blocks`，有效带宽至少 2048。分派中其他守卫仍以源码为准，
不能仅凭此表调用跳过 API/布局守卫的 kernel。

### 数据搬运、流水和缓冲生命周期

N 路径直接从压缩带状存储搬入 UB，不展开稠密矩阵。适用条件下以
DataCopyPad 合并列条带；边界元素采用带内裁剪或对已分配存储内的
padding 值进行屏蔽，保证屏蔽先于算术，避免 NaN padding 污染结果。
一般步长和超出 DMA 参数范围的跨度保留通用访问路径。

流水入口在全局 kernel 中构造 TPipe。双槽先搬入下一块，再计算当前块；
输入槽最后一次向量读取结束后才能发布复用事件。重算借用 staging
空间前，必须消费完两槽的未完成访问；标量读取 DMA 数据前必须等待
对应 MTE2_S。已验证的等待和缓冲复用次序不能按 CPU 仿真结果删去。

本版 R32/C128 只重组用于精度判断的非负有限包络 Max：每个 panel
归约到 16 个列分组，跨 panel 保留分组最大值，在 tile 结束时合并。
原包络值已经过清洗；Max 结合顺序不改变最终结果。复数乘法、浮点求和
树、有序重算、GM 访问与 Host 分派保持不变。额外 2048 字节 UB 仅在
n>128 时申请，单 panel 路径保持原实现。

R32/C128 的短输入路径只初始化实际使用的 32 列对齐前缀。行偏移和
复数索引按编译期固定长度展开，依据公开参数 n 选择 32/64/96/128 列
前缀；写入值、次序与未使用区域保持不变。加载和向量计算使用实际
对齐列数，补零仍保留 C128 求和树的全部零叶，不改归约次序。

当既有 Host 分派选择 R32/C128 且 `0<n<=128` 时，进入独立的单 panel
kernel。此入口省去不可能发生的多 panel 循环与包络合并控制；每行
仍保留 C128 求和树、全部补零叶、有效列计数、掩码及重算判据。
只有首个有效 tile 的原始 A/x 搬运被提前到独立索引缓冲初始化之前，
计算仍消费 slot0 的 MTE2_V 事件；后续 tile 按原流程加载。空核与
无贡献区间不发起该预取，输入槽不能提前供重算覆盖。n>128 仍使用
原有多 panel 入口，不改变公开几何分派的其他守卫。

小 T/C 的既有 TC64×8 入口同样将首 tile 的原始 A/x Load 提前到
MakeIndices 之前。预取仅在有有效输出、alpha 非零且带内区间非空时
执行，Process 跳过该首 tile 的重复 Load，其余 tile/panel 流程不变。
原有 Compute 的 MTE2_V 等待、槽复用、共轭处理、求和和有序重算均保留。
索引初始化使用与 DMA 目标不重叠的 UB 区域，搬运地址、长度及 UB 分配
未改变。该模板开关只允许普通 K64/R8 T/C 入口，其他 T/C、宽带与 N
入口保留原实现；未采用另行测试的 CreateVecIndex 索引重写。

R32 的按需扫描按 512 项搬运，保留 C128 计算块及块间累加顺序；
最多 14 个缓存块只供紧接该行扫描的重算使用，不能跨 API 调用复用。
缓存由重算消费后立即失效，调用者下一次修改 A/x 后仍读取新输入。

R96 将逐 panel 的异常包络替换为“累计有效位 + tile 末尾清洗”：
逐元素检查 pr<4096，并将各 panel 的判据按位 AND；同时保留同次序
的包络 Max。在任何跨列归约前，判据为假的 lane 统一置为 1e30。
若所有 panel 判据为真，其数值和 Max 顺序与原实现相同；若任一次
为假（包括 NaN/Inf），最终 sentinel 与原逐 panel 清洗的结果相同。
这只减少反复遍历包络的成本，复数算术、求和顺序和重算阈值不变。
新增有效位缓冲 384 字节，追加在既有 UB 分配之后，既有地址不移动。

R96 的紧凑批量重算仅在当前调用已缓存的正常输入块、且正常前缀条件
满足时，以向量流水屏障替代一次 V_S/S_V 往返。该条件下中间没有
标量 UB 写入，紧接的 AllCertified 会生成判据并保留最终 V_S 发布，
之后才允许标量读取。未缓存、异常前缀及其他模板仍执行原来的等待。
缓存不能跨 API 调用或跨输入版本复用，所有回退和数值判据保持不变。

### 数值语义与重算

保持 FP32 复数运算，不能通过低精度转换满足性能。快速归约可能改变
消去误差，故保留包络/精度判据与有序重算。R64 的递增列累加顺序、
R96 的 batch scan 与 compact index、R128 的有序累加均来自已验证版本。
重算读取原输入并计算真实输出，不能读取 golden 或按用例编号开关。
特殊值及退化情形仍由公共复数运算和通用路径覆盖。

### 内存与兼容性

接口不新增临时 GM workspace。静态显式 UB 因路径而异，旧版统一
28,768 字节的描述已失效。本版主要宽 tile 路径的最大显式分配为：

| 路径 | 静态显式 UB 字节 |
| --- | ---: |
| R32/C128，启用 partial Max | 186912 |
| R64 | 184096 |
| R96 compact replay + 累计有效位 | 153248 |
| R128 | 186656 |

以上是源码分配分析，不是 profiler 实测峰值。主机句柄既有 workspace、
输入输出分配、驱动和运行时占用不能混计为新增 kernel workspace。
任务书内存验收项为“不涉及”；按要求提供内存报告，并明确统计口径。

公共接口复用主仓已有的 aclblasCgbmv 声明、句柄/状态码/stream。
算子目录整理为 6 个编译单元与 9 个头文件，共 15 个文件。六个编译
单元分别负责 Host、通用 kernel、N 流水、R64、短带距和 T/C 入口；
头文件按以下职责分组，避免为逐次实验保留大量碎片文件：

分组保留了 30 个原头文件的有效正文与 6 个编译单元正文，只删除未被

### 支持硬件和约束

目标为 CANN 9.1.0、Atlas A2/A3 训练与推理系列（含 Atlas 800I A2/A3）。
已实测环境为 HiDevLab 910B3、CANN 9.1.0；此结果不能写成 A3 或所有
目标整机均已实测。使用 CANN 配套毕昇编译器、dav-2201、Release -O3。
