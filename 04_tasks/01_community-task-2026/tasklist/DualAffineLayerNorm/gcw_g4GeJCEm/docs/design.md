# 需求背景（required）

## 需求来源

【xLLM】【2026年10月社区任务】双分支 LayerNorm 算子开发。在 xLLM 侧新增 `DualAffineLayerNorm`：对同一输入一次归一化后接两组仿射参数，输出两路结果，替代"两次 LayerNorm"的重复统计与重复读。

## 背景介绍

基线做法是把同一张量分别过两次 LayerNorm（各自求均值方差、各读一次输入），统计与访存均重复一倍。本算子的价值在于**统计只做一次、输入只读一次**，双分支只增加一次逐元素仿射与一次写。设计目标为单 kernel、零全局工作区、FP16/BF16 输入输出、内部 FP32 统计。

# 需求分析（required）

## 需求描述

输入 `x[N,H]`（FP16/BF16，N∈[1,4096]、H∈[1,8192]）与 `gamma1/beta1/gamma2/beta2[H]`、标量 `epsilon∈[1e-7,1e-2]`；输出 `y1,y2[N,H]`，dtype 与输入一致。全部统计与归一化在 FP32 完成，输出一次舍入转回目标 dtype。

## 需求拆解与边界

1. 方差按有偏（分母 H）口径，与任务书 CPU FP64 标杆一致。
2. 常量行与 `H=1` 必须精确输出对应 `beta`——由 `var=0 → z=0` 的乘法结构保证，不靠特例分支。
3. 非法输入（非 2 维、非连续、dtype 越界、N/H 越界、仿射形状不符、输出别名、epsilon 越界或类型错误）在三个入口一致报错，不做静默回退。
4. 不修改输入；每次调用返回新分配的独立输出，输出之间及输出与输入存储互斥。

# 详细设计（required）

## 算子分析

采用**两趟统计**（先求均值并居中，再对居中值求平方和）而非单趟 `E[x²]−μ²`：在高偏置输入场景下单趟的两项几乎相等，其相对差低于 FP32 可分辨精度，方差会被舍入噪声淹没甚至变号；两趟先减均值使平方项量级回落到 O(var)，FP32 足够。该取舍以数值模型逐项验证（CPU 侧镜像 kernel 算术，含负对照），非硬件结论。

输出转换用最近舍入，与社区同代 layer_norm 实践的代际口径一致；与 numpy 的差异仅出现在半 ulp 边界，远小于容差。

## 算子实现

- **分核**：按 AIV 核数与行数取小者铺核，前核/尾核式行分配，核间行区间互斥，无核间同步、无原子写；仿射参数每核只读入片上一次，行循环全程复用。
- **片上缓冲**：输入双缓冲、参数队列、FP32 居中/归一缓冲、输出段队列分层复用，最坏形状下 UB 占用约八成容量、余量固定；缓冲尺寸全部由 H 对齐值与固定段长推出，不硬编码核数与 UB 容量。
- **访存**：整行连续搬运并支持非对齐 H（右侧 pad，pad 不参与归约）；输出分段连续写，使搬运与向量计算、写回与下一段计算重叠。
- **工作区**：显式全局工作区为 0，每次调用只新增两个输出张量的分配。
- **接口**：ACLNN 两阶段 API（由 op 工程从 OpDef 自动生成，`.run` 私有安装）+ Kernel 直调交叉验证入口（与 op_host 同一 tiling 划分逻辑、逐字段同布局）+ Python 侧 `prepare / run / run_direct` 三入口；`run` 为验收入口。
- **标量/向量同步**：归约取标量、标量回乘向量、开方前后按代际要求显式插入同步事件。

## 支持硬件

Atlas A3（含 910C）为主目标，Atlas A2 同代码路径适配；FP16 与 BF16 各自独立出核。

# 可维可测分析

## 精度标准

Golden 为独立 CPU FP64 实现；判定 FP16 `atol=rtol=2e-3`、BF16 `2e-2`，逐元素全矩阵比对。公开用例 46 条 + 额外输入 12 条，另含 offset/tiny/limits 等边界形态。数值侧给出分场景误差预算，并对常量行、`H=1`、epsilon 下界回退等语义做断言。

## 性能标准

按任务书冻结协议（预热 50、5 轮 × 200、轮均中位数、`api_to_completion_wall_time`、入口 `run`）逐项对照 `performance_targets.json`。小用例耗时由 host 发射主导，故设计上以「零工作区 + 校验前置到 C++ + 无额外同步拷贝 + executor 复用」压固定开销；大用例靠满铺核与访存/计算重叠。

## 内存与工程验收

峰值增量控制在「输出字节数 + 16 KiB 上限」内；覆盖多 stream、提前释放、偏移存储输入、重复调用回收等生命周期场景，以及 20 类非法输入在三个入口的一致行为。

## 交付件

算子工程（op_host/op_kernel/op_api）、两阶段 API 与直调入口、独立 C++ 调用样例、公开与扩展用例自验记录、按官方模板出具的精度/性能/内存自测报告与可复现步骤说明。
