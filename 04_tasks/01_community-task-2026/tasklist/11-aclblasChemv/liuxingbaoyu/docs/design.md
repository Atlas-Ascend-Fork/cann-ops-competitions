# aclblasChemv 算子设计文档

# 需求背景（required）

## 需求来源

本需求来自 11 月社区任务“aclblasChemv 算子开发（A2/A3）”。使用 Ascend C 实现单精度复数厄米特矩阵与向量的乘加运算，完成 Atlas A2/A3 平台适配及配套自验证。

## 背景介绍

### aclblasChemv 算子开发

厄米特矩阵具有共轭对称性，可以通过指定的一个三角区域确定完整矩阵。本算子结合复数标量 alpha、beta，完成矩阵向量乘法与原输出向量的加权合并，将结果写回 y。

### 现有方案分析

ops-blas 已有实数对称矩阵向量乘及复数矩阵向量乘等相关实现，可参考其工程组织、数据访问和计算方式。本任务补齐 A2/A3 的 Chemv 能力，重点保证三角引用、共轭关系及复数乘累加语义。

### 算子功能分析

| 参数 | 含义 | 数据类型 | 形状及约束 |
| --- | --- | --- | --- |
| handle | 携带执行 stream 的库句柄 | aclblasHandle_t | 有效非空句柄 |
| uplo | 参与计算的矩阵三角区域 | aclblasFillMode_t | ACLBLAS_UPPER 或 ACLBLAS_LOWER |
| n | 矩阵阶数及向量逻辑长度 | int | n≥0，n=0 快速返回 |
| alpha、beta | 复数缩放标量 | COMPLEX64 | Host 或 Device 内存中的单值 |
| A | 厄米特矩阵 | COMPLEX64 | Device 内存，列主序，逻辑形状 `[n,n]` |
| lda | 矩阵前导维度 | int | 正常计算时 lda≥max(1,n) |
| x | 输入向量 | COMPLEX64 | Device 内存，逻辑形状 `[n]` |
| y | 输入及原地输出向量 | COMPLEX64 | Device 内存，逻辑形状 `[n]` |
| incx、incy | 向量元素访问步长 | int | 支持正负步长，跨度满足接口要求 |

复数由两个 FLOAT32 分量组成。A 按 uplo 指定区域参与计算，对角线仅采用实部，另一侧元素按共轭对称关系确定。

# 需求分析（required）

## 需求描述

基于 ops-blas 工程，以句柄式 BLAS 接口直调 Ascend C Kernel，实现 A2/A3 平台的 aclblasChemv。支持上下三角、列主序前导维度、向量正负步长及复数标量的不同存储位置，功能和边界行为遵循任务书约定。

## 需求拆解

1. 实现厄米特矩阵向量乘加，保证三角引用、对角线及共轭处理正确。
2. 支持列主序矩阵和前导维度 padding，以及向量的连续、正负步长访问。
3. 支持 alpha、beta 的 Host、Device 及混合模式，正确处理零标量和快速返回。
4. 完成接口校验、复数计算和规模适配，达到任务书的精度及性能目标。
5. 完成接口接入、构建和测试注册，提供完整的自验证材料。

# 详细设计（required）

## 算子分析

### 数学公式

对逻辑输出位置 i，计算：

```text
y_new[i] = alpha × sum(H[i,j] × x[j], j=0..n−1) + beta × y_old[i]
```

其中 `0≤i<n`，H 表示根据 uplo 从 A 的指定三角区域解释出的厄米特矩阵。指定三角内的非对角元素直接采用存储值，另一侧使用对应元素的复共轭，对角元素取实部并将虚部视为零。

beta 为零时直接形成输出，计算过程跳过 y 的旧值读取。alpha 为零时按任务书执行缩放或快速返回，省略 A、x 的访问。

### 支持数据类型

A、x、y、alpha 和 beta 均使用单精度复数，实部与虚部为 FLOAT32。输出保持 COMPLEX64，实部与虚部按照任务书规定的精度标准分别验证。

### 支持形状

A 的逻辑形状为 `[n,n]`，物理存储按列主序覆盖 `lda×n` 个复数元素。x、y 的逻辑形状均为 `[n]`，n>0 时各自存储至少覆盖 `1+(n−1)×abs(inc)` 个复数元素。

支持上下三角、不同矩阵阶数、非对齐规模、前导维度 padding 和正负向量步长。

## 算子实现

### 实现方案

整体采用 Host 参数处理与设备侧分块矩阵向量计算相结合的方式。根据规模和布局组织并行工作，按指定三角访问矩阵数据，完成复数乘累加后与 beta 缩放的旧输出合并。

#### 3.2.1 host 侧设计

Host 侧按任务书规定的顺序检查句柄、n、uplo、lda、步长及标量指针。识别 alpha、beta 的存储位置，按照绑定 stream 的执行顺序获取标量，并依据其取值处理快速返回及 A、x、y 的条件判空。

结合平台资源、矩阵规模和向量布局生成 tiling 信息，合理安排计算范围与片上缓冲。地址范围采用足够宽的整数计算并进行溢出检查，合法计算任务通过 handle 绑定的 stream 下发。

#### 3.2.2 kernel 侧设计

Kernel 侧围绕输出向量组织矩阵数据读取、复数乘累加与结果写回。仅访问 uplo 指定的矩阵三角，按共轭对称关系处理所需元素，对角线虚部按零参与计算。

通过分块搬运和片上数据复用降低重复访存，结合不同规模控制并行及归约开销。连续布局作为重点优化路径，跨步访问与前导维度 padding 按接口语义处理。

输出阶段根据 alpha、beta 完成结果合并，beta 为零时跳过旧 y 的读取。仅写回有效向量位置，保证尾部和步长间隙中的数据正确。

#### 3.2.3 接口与工程接入

对外提供以下接口，沿用 ops-blas 的句柄、复数类型、枚举和状态码约定：

```cpp
aclblasStatus_t aclblasChemv(
    aclblasHandle_t handle,
    aclblasFillMode_t uplo,
    int n,
    const aclblasComplex* alpha,
    const aclblasComplex* A,
    int lda,
    const aclblasComplex* x,
    int incx,
    const aclblasComplex* beta,
    aclblasComplex* y,
    int incy);
```

实现接入 arch22 构建分支，并补齐对应 GTest 注册。接口声明、产品支持说明和测试调用保持一致。

## 算子约束限制

- handle 为空时返回 `ACLBLAS_STATUS_HANDLE_IS_NULLPTR`。handle 检查通过后，n<0 返回 `ACLBLAS_STATUS_INVALID_VALUE`，n=0 直接返回成功。
- 正常路径校验 uplo、lda、步长及 alpha、beta 指针。非法 uplo 返回 `ACLBLAS_STATUS_INVALID_ENUM`，其他非法参数按任务书返回对应错误码。
- 步长要求非零且不为 INT32_MIN，跨度按任务书要求检查。
- 完成规定校验并获取标量后，alpha 为零且 beta 为一时直接返回成功，此时 A、x、y 可为空。
- alpha 为零时 A、x 可为空。其他计算路径按任务书检查 A、x、y，beta 为零时 y 仍须具备有效输出存储。
- 矩阵仅读取指定三角，对角线虚部忽略，输出仅更新 y 的有效元素。
- 执行通过绑定 stream 下发，调用方在读取结果前同步，并保证相关存储在任务完成前有效。
- Inf/NaN 输入及输出按任务书的特殊值规则验证。

精度验证覆盖完整输出向量，包括上下三角、对角线虚部、不同矩阵规模、前导维度 padding、正负步长、不同标量存储位置，以及 alpha/beta 特殊取值。补充快速返回、空指针、非法枚举、跨度溢出、特殊值及任务书要求的输入分布场景。

性能测试覆盖配套的全部性能用例，按任务书要求使用 msprof op 采集单算子 task duration。预热 5 次后，连续执行至少 10 次有效采样，取算术平均作为单次耗时，逐项记录 GPU 标杆耗时、NPU 实测耗时和判定结果。

自验证材料包含环境、执行步骤、用例结果和原始日志。内存部分按交付模板说明实际验证内容，任务书未单独设定峰值内存指标。

## 兼容性分析

接口采用 ops-blas 统一类型及状态码，参数顺序与任务书定义一致。A2/A3 的三角引用、标量处理、校验顺序和边界语义遵循任务书约定，通过 arch22 分支接入现有工程，并对同族接口执行必要的构建及回归验证。
