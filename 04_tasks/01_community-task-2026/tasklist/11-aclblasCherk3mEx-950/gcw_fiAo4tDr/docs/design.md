# 需求背景

## 需求来源

2026 年 11 月 CANN 社区任务 `aclblasCherk3mEx`。目标平台为 Ascend 950PR，代码基于 `cann/ops-blas`，使用 Ascend C 和句柄绑定的 stream 直调。

## 背景介绍

### 现有实现与参考接口

`ops-blas` 的现有 `aclblasCherk` 提供 Hermitian 秩-k 更新，`blas/gemm/arch35/` 的复数 GEMM 提供片上三实数乘积的实现基础。本任务新增直调 Ex 接口，和 cuBLAS `cublasCherk3mEx` 保持参数顺序及列主序语义。CPU 数学参考使用 Netlib CBLAS 的非 3M HERK。

### 算子功能分析

算子在一次 kernel 下发内计算实数缩放的 Hermitian 秩-k 更新。输入矩阵支持复数 FP32 或交错复数 INT8，输出为复数 FP32。`uplo` 选择输出三角区域，`trans` 选择原矩阵或共轭转置。

# 需求分析

## 需求描述

计算 `C ← α X Xᴴ + β C`，其中 `X = A` 或 `X = Aᴴ`。仅访问和更新 `uplo` 指定的 C 三角区域。更新后的对角虚部为零，另一三角及 `ldc` 填充保持原样。

## 需求拆解

- 在 `include/cann_ops_blas.h` 暴露标准签名，`blas/herk/arch35/` 提供实现。
- 校验 handle、枚举、尺寸、前导维度及必需指针，覆盖 Host 和 Device 标量。
- 提供常规矩阵、短 K、长 K、前导维度填充和退化输入路径。
- 在 `test/herk/cherk3m_ex/arch35/` 接入 CSV 驱动测试与性能采集。

# 详细设计

## 算子分析

### 数学公式

令 `X = Xr + i·Xi`。三个实数乘积为：

```text
P0 = Xr · Xrᵀ
P1 = Xi · Xiᵀ
P2 = (Xr + Xi) · (Xr − Xi)ᵀ
Re = P0 + P1
Im = P2 − P0 + P1
```

Cube 复用仓内等价 Gauss 分解。对每对复数 `b = br + i·bi` 和 `a = ar + i·ai` 计算 `p = (br + bi)·ar`、`q = br·(ai − ar)`、`r = bi·(ar + ai)`，得到 `Re = p − r`、`Im = p + q`。两侧打包时正确应用共轭，计算目标为 `X Xᴴ`。

### 支持数据类型

| 数据 | 支撑类型 |
| --- | --- |
| A | `ACL_COMPLEX64` 或 `ACL_INT8` |
| C | `ACL_COMPLEX64` |
| α、β | Host 或 Device 上的 FP32 实数 |

复数 INT8 以两个有符号字节交错存储。两分量精确提升到 FP32，之后再执行共轭和加减。

### 支持形状

C 为列主序 `ldc × n`，逻辑区域为 `n × n`。A 在 `OP_N` 时为 `lda × k`，在 `OP_C` 时为 `lda × n`。分别校验 `lda ≥ max(1,n)` 或 `lda ≥ max(1,k)`，并校验 `ldc ≥ max(1,n)`。支持尺寸尾块和前导维度填充。

## 算子实现

### 实现方案

#### Host 侧设计

1. 依次校验 handle、枚举、尺寸和前导维度，再校验指针和类型。非法 `OP_T` 返回 `ACLBLAS_STATUS_INVALID_ENUM`。
2. `n=0` 直接返回。 `k=0` 或 `α=0` 时跳过 A，`β=1` 时保留整个 C。
3. Host 标量按值传递，普通 Device 标量由计算 kernel 在同一 stream 上读取。当 A 为空且合法性取决于 Device 上的 α 时，同步读取该标量以确定 API 返回值。
4. 依据尺寸、布局、标量位置和可用核数选择路径。仅缩放和常规 Device 标量场景使用 SIMT。Cube 处理计算量较大的矩阵，也覆盖 `OP_N` 上三角、`α=1`、`β=0` 且 `n`、`k` 均大于等于 16 的小型复数 FP32 矩阵。

##### 分核策略

SIMT 将方阵元素按列主序展开，由各线程跨步遍历，只计算目标三角内的元素。Cube 以输出块为调度单位，沿目标三角分配任务，块数决定参与核数。短 K 上三角场景满足末轮分配条件时，将对角块优先交给块数较少的核组。

##### 数据分块与片上存储

常规 Cube 的输出块为 64×64。短 K 共轭转置专用路径使用 128×128 输出块。输入块和输出阶段在片上切换缓冲，三份乘积沿 K 方向累积并就地归并。转置、输入类型、块数和标量信息由 Host 随 tiling 传给 kernel。

#### Kernel 侧设计

- **SIMT**。每个线程负责目标 C 的一个或多个元素。分段计算三个乘积，虚部抵消或异常幅值触发带舍入补偿的 3M 重算。
- **常规 Cube**。以 64×64 对输出三角分块，每个输出块由同一组 AIC 与 AIV 负责。AIV 负责交错输入打包、片上结果归并和三角写回，AIC 负责三个 FP32 矩阵乘积。非 INT8 长 K 按 256 分段归并，避免长乘加链带来的误差。
- **短 K 常规分块**。处理上三角时，若末轮仅占用部分核心且剩余核心足以处理所有对角块，则将对角块分配给块数较少的核心。复数 FP32 采用两级输出缓冲，让下一块的输入打包与上一块的写回重叠。
- **短 K Cube**。对上三角、共轭转置、标准缩放的复数 FP32 输入采用 128×128 输出块。短输入面板直接打包，减少同一输入的重复搬运。
- **输出保护**。对角块按列裁剪实际写回范围。对角虚部写零。`β=0` 时跳过 C 旧值读取。非有限输入采用 IEEE 特殊值处理。

各计算路径在单次 kernel 下发内完成。片上分段累加和归并使用 L1、L0、UB 缓冲，避免落盘三个完整乘积矩阵。

## 支持硬件

| 支持的芯片版本 | 涉及 |
| --- | --- |
| Ascend 950PR（arch35） | 是 |

构建要求 CANN 和 asc-devkit 9.1 或更高版本。自测使用 CANN 9.1.0。

## 算子约束限制

`trans` 仅支持 `OP_N` 和 `OP_C`。A 的可读区域和 C 的可写区域应互不重叠。调用方在 Host 读回结果前同步 handle 绑定的 stream。

## 精度标准/性能标准

| 验收标准 | 描述 | 标准来源 |
| --- | --- | --- |
| 精度 | Netlib BLAS 3.10.0 `cblas_zherk` 以 FP64 生成 golden，再收窄到复数 FP32。实部和虚部分别比较，`atol = rtol = 2⁻¹³`，匹配率至少 99%，绝对误差上限为 `1e-2` 或 `32×ULP`。 | 任务书 §3.2 |
| 性能 | 每例预热 5 次，取 10 次 `msprof op` 的 kernel `Task Duration(us)` 平均值。与同例 GPU kernel 基线比较，单例 GPU/NPU 至少 0.4，整体算术平均至少 0.5。INT8 补测沿用对应复数 FP32 的 GPU 基线。 | 任务书 §3.3 |
