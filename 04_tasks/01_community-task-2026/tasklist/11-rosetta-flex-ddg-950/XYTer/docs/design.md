# Rosetta Flex ddG 端到端异构加速 设计文档

## 需求背景

来源：[官方任务书页面](https://www.hiascend.com/activities/task-center/details/4373d1139dfe4ba7b448a8ef5cc3596b)。目标平台：24 核 CPU + 单张 Ascend 950PR。

在任务书规定的平台上，交付兼容参考应用的批处理入口。主机负责调度、输入输出和汇总；设备侧只替换经过验证的纯数值计算环节。

## 需求分析

沿用任务书 §2.3–2.4 的命令行：`--selected`、`--pdb-dir`、`--xml`、`--cpu-cores`、`--device-id`、`--seed`、`--work`、`--out`、`--summary`。输入验证失败时返回非零，按原输入顺序生成 22 列结果 CSV 和运行摘要 JSON。

## 详细设计

### Host

保留参考应用的任务顺序和随机入口。线程池并行处理相互独立的工作项；用稳定任务 ID 在输出端重组结果。约束 CPU 核数和设备队列长度，以日志记录阶段计时、完整度和错误。

### 计算与数据搬运

首先以 CPU 参考实现建立逐阶段的数据合同。只把接口稳定、支持批处理的数值操作封装为设备任务，增量核对输出和舍入；合并小传输并复用固定容量缓冲。结果汇总和源数据解析继续沿用主机实现。

### 实现侧重点

主机按稳定的工作项编号分派，结果以编号归并。先用小批次对齐输出顺序，再扩展到任务书全量。

## 可维可测分析

校验命令行、CSV/JSON 格式、结果完整度和重复运行一致性，精度以任务书 §3.2 的官方验证脚本为准。性能按 §3.3 从读取输入到写完结果的端到端墙钟时间记录，正式上限 5565.3 s；一次性环境安装和编译分开统计。
