# aclblasChpmv 设计文档

## 需求背景

压缩 Hermitian 矩阵直接与向量相乘。每个对角元素只取实部，镜像元素取共轭。复数结果原地更新到 y。

目标平台为 Atlas A2/A3（arch22），性能验收使用 Atlas 800T A2（910B3）。本方案采用压缩列流式扫描。[官方任务及附件](https://www.hiascend.com/activities/task-center/details/c596a05d90b9471683e41fcf4d026ae5)

## 需求分析

沿用 ops-blas 公共头文件的入口、枚举和状态码。Host 按任务书 §2.4–2.5 校验结构参数，区分空规模、标量短路和实际读写张量的情形。设备侧从 handle 绑定的 stream 执行，所有地址计算使用能容纳物理跨度的整数。

使用非纯实的非对角元素和带虚部的主对角，分别验证上、下存储得出相同结果。负 incx/incy 的逻辑起点为 (1−长度)×步长；对间隙填入哨兵。

## 详细设计

### 压缩列流式扫描

把连续的 AP 按列段分给各核。一个非对角元素 a 同时贡献 a*x[j] 与 conj(a)*x[i]，一个对角元素只贡献一次。各核向独占的 FP32 实虚部分和区写入，后续按固定核顺序合并到 y。

部分和区按输出窗口复用；对 n 较小的输入直接在单核归约。以 AP 读取字节数、工作区往返和两阶段总耗时衡量分界。

实现落在 `blas/spmv/arch22/`，GTest 接入 `test/spmv/chpmv/arch22/`。同一 API 在不同 tiling 下采用相同的参数校验与数据类型约定。对齐搬运的最后一段以逻辑末元素为界，必要时用带掩码的存取处理尾部。

## 可维可测分析

在设备侧通过公共 API 发起计算，用 Netlib CHPMV 生成独立参考值。每个用例保留随机种子、输入类型、期望状态与实际状态；正常输出按用例的 `mere_threshold` 和 `mare_multiplier` 核对，复数输出分别统计实部和虚部。计数由本期随包 CSV 得出。

| 官方用例表 | 精度及契约用例 | 性能用例 |
| --- | ---: | ---: |
| `chpmv_test.csv` | 1000 | 200 |

正式性能采集先预热 5 次，后取 10 次有效调用。用 msprof op 读取 Task Duration，每次先合计该调用的计算内核再求均值，换算为 ms 后与对应变体的 gpu_baseline.csv 对齐。每项 NPU 平均内核时间 ≤ 对应 GPU 基线的 1.25 倍。记录实际加载的库、设备和原始计时。任务书 §3.4 将内存专项列为不涉及。
