# aclblasCgemm3m 设计文档

## 需求背景

在列主序 COMPLEX64 输入上计算 C=alpha·op(A)·op(B)+beta·C。两输入独立支持不转置、转置与共轭转置。

目标平台为 Atlas A2/A3（arch22），性能验收使用 Atlas 800T A2（910B3）。本方案采用复用已打包面板。[官方任务及附件](https://www.hiascend.com/activities/task-center/details/cae74cb900484862a2b43b24c0f7d9d3)

## 需求分析

沿用 ops-blas 公共头文件的入口、枚举和状态码。Host 按任务书 §2.4–2.5 校验结构参数，区分空规模、标量短路和实际读写张量的情形。设备侧从 handle 绑定的 stream 执行，所有地址计算使用能容纳物理跨度的整数。

以复数输入和非实标量覆盖九种转置组合。测试 K 尾块、非紧凑前导维以及实虚部消去；对两个分量分别核对混合误差。

## 详细设计

### 复用已打包面板

按逻辑运算方向提取 Ar、Ai、Br、Bi，遇共轭时先变更虚部符号。生成面板实部、虚部与两者之和；同一计算核完成 P=ArBr、Q=AiBi、R=(Ar+Ai)(Br+Bi)，恢复 (P−Q,R−P−Q)。

按输出矩形分核，共用的输入面板在相邻输出块间复用；beta 为零时跳过旧 C 读取。工作区包括打包和对齐尾块，显式检查尺寸乘积。

实现落在 `blas/gemm/arch22/`，GTest 接入 `test/gemm/cgemm3m/arch22/`。同一 API 在不同 tiling 下采用相同的参数校验与数据类型约定。对齐搬运的最后一段以逻辑末元素为界，必要时用带掩码的存取处理尾部。

## 可维可测分析

在设备侧通过公共 API 发起计算，用 Netlib CGEMM 生成独立参考值。每个用例保留随机种子、输入类型、期望状态与实际状态；正常输出按用例的 `mere_threshold` 和 `mare_multiplier` 核对，复数输出分别统计实部和虚部。计数由本期随包 CSV 得出。

| 官方用例表 | 精度及契约用例 | 性能用例 |
| --- | ---: | ---: |
| `cgemm3m_test.csv` | 1000 | 200 |

正式性能采集先预热 5 次，后取 10 次有效调用。用 msprof op 读取 Task Duration，每次先合计该调用的计算内核再求均值，换算为 ms 后与对应变体的 gpu_baseline.csv 对齐。每项 NPU 平均内核时间 ≤ 对应 GPU 基线的 1.25 倍。记录实际加载的库、设备和原始计时。任务书 §3.4 将内存专项列为不涉及。
