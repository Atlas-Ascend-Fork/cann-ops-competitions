# Atlas A2/A3 批量实数矩阵向量乘设计

## 需求背景

### 需求来源

11 月社区任务《aclblasSgemvBatched 类算子开发任务书》（2026-11-24 修订）要求在 CANN 9.1.0、Atlas A2/A3 上，以 Ascend C 实现五个指针数组形式的 GEMV 接口。对标 cuBLAS 同名变体，数学定义遵循 Netlib SGEMV。一个调用包含多个独立矩阵，各批次地址可以离散。[ops-blas 工程](https://gitcode.com/cann/ops-blas) · [Netlib SGEMV](https://www.netlib.org/blas/sgemv.f)

### 背景介绍

任务书给出的复用起点为 arch35 的实数入口、变体分派及测试工程，以及 arch22 的复数批处理入口。前者用于对齐五个公开接口及测试调用，后者用于核对 arch22 的构建注册、流和设备指针表传递。实数计算不包含共轭和复数乘加。移植时须在 CANN 9.1.0 上核对向量指令、转换指令和尾块搬运能力。

## 需求分析

五个入口沿用 `include/cann_ops_blas.h`。参数依次为 handle、trans、m、n、alpha、Aarray、lda、xarray、incx、beta、yarray、incy、batchCount。alpha、beta 均为 Host 端 FP32 标量。三张指针表均位于 Device，每张表有 batchCount 个元素。

| 公开接口 | A、x | 累加及缩放 | y 原地读写 |
| --- | --- | --- | --- |
| aclblasSgemvBatched | FP32 | FP32 | FP32 |
| aclblasHSHgemvBatched | FP16 | FP32 | FP16 |
| aclblasHSSgemvBatched | FP16 | FP32 | FP32 |
| aclblasTSTgemvBatched | BF16 | FP32 | BF16 |
| aclblasTSSgemvBatched | BF16 | FP32 | FP32 |

半精度接口的 uint16_t 承载浮点位模式。内核须按入口解释位模式，先转换为 FP32，完成点积与缩放后只在写回处按输出类型舍入一次。各批次共用尺寸和标量，不做广播。调用方保证所有 y 写区域彼此独立，且与 A、x 读区域不重叠。

## 详细设计

### 算子分析

对批次 b 计算 `y = alpha × op(A) × x + beta × y`。每个 A 的物理存储恒为 lda × n，元素 A(r,c) 位于偏移 r+c×lda，只有前 m 行有效。实数 C 与 T 共用转置路径。

| trans | 输出长度 L | 归约长度 K | 输出 j 的点积项，第 k 项 |
| --- | ---: | ---: | --- |
| N | m | n | A(j,k) × x(k) |
| T 或 C | n | m | A(k,j) × x(k) |

长度为 l、步长为 s 的向量将逻辑下标 t 映射为 `(s < 0 ? (1-l)*s : 0) + t*s`。地址运算先扩展到有符号 64 位。取 m=2、n=3、lda=4 做转置时，三个点积分别读取矩阵偏移 (0,1)、(4,5)、(8,9)。若 incx=-2，每个点积依次读 x[2]、x[0]。该例可同时检出转置后误换 lda 下界、误读列填充和负步长起点错误。

### Host 参数校验与下发

| 次序 | 检查项 | 处理 |
| --- | --- | --- |
| 1 | handle 为空 | 返回 ACLBLAS_STATUS_HANDLE_IS_NULLPTR |
| 2 | trans 超出 N/T/C | 返回 ACLBLAS_STATUS_INVALID_ENUM |
| 3 | m 或 n 为负、lda 小于 max(1,m)、步长为零、batchCount 为负 | 按表述顺序检查，返回 ACLBLAS_STATUS_INVALID_VALUE |
| 4 | alpha 或 beta 指针为空 | 返回 ACLBLAS_STATUS_INVALID_VALUE，空工作量也检查 |
| 5 | 非空工作量下任一指针表为空 | 返回 ACLBLAS_STATUS_INVALID_VALUE。只检查表地址，由设备按需取成员 |
| 6 | batchCount、m、n 中任一为零 | 返回 SUCCESS，允许三个表为空，无设备访问和 kernel 下发 |

结构检查通过后读取标量。alpha=0 且 beta=1 时直接返回。其余 alpha=0 情形只访问 y 表，beta=0 时直接写零，其余情形按步长缩放。常规乘加中 beta=0 同样跳过旧 y 的加载，避免旧 NaN 污染结果。Host 将标量值、维数、步长、分块信息及表地址传入 handle 绑定的 stream，异步下发，调用方在读回前同步。

**待评审边界**：任务书允许任意非零 int 步长，自验 README 将 INT_MIN 列为非法值。建议实现普通寻址时先扩宽再乘，另将 INT_MIN 用例与期望状态单列，请评审确认接口约束。跨批次输出重叠属于调用方约束，测试侧在构造地址时检查，Host 不扫描设备指针表。

### Kernel 分核与分块

每个工作单元拥有一个批次的一段输出，独占该段从归约到写回的全过程。设每段包含 R 个输出，总单元数为 batchCount × ceil(L/R)。按可用向量核数启动 block，核按 block 数跨步领取单元。各单元在设备端解析自己的批次地址，避免 Host 逐批次下发。优先让相邻输出段在满足写回对齐的位置分界。短输出或非对齐、跨步写回无法安全分段时，改为一核负责整个批次，并使用精确元素写回，防止相邻核覆盖同一写回块。

| 路径 | 搬入与计算 | 写回 |
| --- | --- | --- |
| N | 连续取同一列的 R 行，在 UB 中维护 R 个 FP32 累加器。按 K 分片读 x，每项 x 广播到对应列片，沿列累加。窄矩阵优先合并多个输出行，共用 x 分片 | 对该行段统一应用 alpha 和 beta，按 incy 写回 |
| T/C | 每个输出对应一列。沿该列连续搬入有效行，与同一段 x 做向量乘法及分段归约，片段和保存在 FP32。相邻列复用 UB 中的 x | 每列完成全部 K 项后写一个输出 |
| 非单位步长 | 正负步长沿逻辑下标读写。连续部分走批量搬运，离散 x 在核内按实际地址收集成紧凑片段 | 离散 y 仅写命中元素，保持间隙原值 |

Host 按平台可用 UB 估算矩阵片、x 片、FP32 转换临时区、累加器、输出和对齐开销。只有两套搬入缓冲与临时区的总量可容纳时才启用双缓冲，否则缩小片长或使用单缓冲。最后一片按实际有效元素数计算，补零只发生在核内。输入输出的地址可能贴近分配边界，不向用户缓冲区外读写对齐尾数。首版使用单次 kernel 完成每次有效调用，无跨核原子加或全局归约工作区。对小 batch、短输出、长归约重点观察空闲核和单核归约耗时，再根据实测决定是否引入分段归约。

### 工程集成与支持硬件

实数入口与 kernel 放入 `blas/gemv_batched/arch22/`，保留既有公开声明。测试放入 `test/gemv_batched/arch22/`，在对应 CMakeLists 中注册。A2 编译入口按任务书为 `bash build.sh --ops=sgemv_batched --soc=ascend910b3`。A3 按实际设备 SoC 编译。分别记录两个目标的编译、运行覆盖情况，并在运行验证后更新算子 README 的支持表。

## 可维可测分析

### 接口与精度

五套 CSV 每套 1000 条精度及接口用例、200 条性能用例。GTest 按接口及用例名记录参数、随机种子和返回码。非法输入核对具体状态码，合法空输入核对无 kernel。用填充哨兵检查 lda 间隙、跨步 y 间隙和尾块。在 alpha=0 时用 NaN 输入检验短路，在 beta=0 时预填 NaN 到 y。另覆盖空表、负步长、独立批次地址、Inf/NaN 传播和低精度收窄。

逐批次按列主序用 Netlib BLAS 3.10.0 的 cblas_sgemv 生成参考结果，参与运算的低精度输入先按原 dtype 量化，再转 FP32，输出按变体舍入。若使用测试工程的 FP64 累加参考，独立标明来源并记录与 cblas 的偏差。逐元素检查绝对误差是否在 atol + rtol × |golden| 内，整例匹配率至少 0.99，同时检查最大绝对误差。特殊值按预期位置、类别和无穷符号另行核对。

| 输出 | atol 与 rtol | 最大误差限（按任务书） |
| --- | --- | --- |
| FP32 | 2^-13 | 1e-2 或 32 ULP |
| FP16 | 2^-10 | 1e-1 或 32 ULP |
| BF16 | 2^-7 | 1e-1 或 32 ULP |

### 性能与兼容性

在 Atlas 800T A2（910B3）上对每个性能点预热 5 次，采集 10 次成功执行的 msprof op Kernel Task Duration，记录原始样本。正式判据为平均微秒数 ≤ 1.25 × gpu_ms × 1000。另用 aclrtEvent 对预置缓冲上的连续 10 次调用计时，输出每次平均值。性能结果须同时保留正确性、有效样本数和基线匹配情况。任务书未设独立内存验收指标。

按变体及 trans、m、n、lda、incx、incy、batchCount、alpha、beta 全键关联 A100 基线。11 月 24 日修订改变了 T/C 用例的 lda 语义，任务书注明原时延需重测；自验说明另标记非默认标量待复测。虽然五张基线表均有 200 个正耗时，仍须核实这些行对应的采样版本，待复测行保留待定状态。分组查看单位步长、跨步、短输出和低精度转换的耗时，定位搬运、归约或调度开销。

arch22 实数实现按架构注册，与 arch35 及既有复数入口分别编译。回归覆盖符号链接、五个接口的类型匹配、绑定流上的先写后读及既有复数测试。本文为开发前设计，精度、性能和硬件支持情况在实现后的自测报告中记录。
