# FusedExponential 算子设计文档

# 1 需求背景

## 1.1 需求来源

完成 CANN 社区“指数分布后处理融合算子开发”任务，使用 Ascend C 实现 FusedExponential。
产品代码提交至 `ops-math/experimental/math/FusedExponential`。

## 1.2 背景介绍

指数分布采样在生成均匀样本后，需要执行 neg、add、比较、masked_fill、log 和 mul。
多个小算子增加调度和 GM 读写，并产生 bool mask 中间张量。
本算子融合后处理，接收已有均匀样本，不负责生成随机数。

# 2 需求分析

## 2.1 需求描述

支持 FLOAT16、BFLOAT16、FLOAT32，输入输出 shape 和 dtype 相同，格式为 ND。
支持 rank 0–8、空张量、非连续输入输出和完全原地调用，不支持广播。

| 参数 | 类别 | 类型 | 说明 |
| --- | --- | --- | --- |
| u | 输入 | Tensor | 均匀样本，调用方保证值域为 [0,1) |
| lambd | 输入 | Host DOUBLE Scalar | 率参数，大于零；允许正无穷 |
| out | 输出 | Tensor | 指数分布后处理结果 |

## 2.2 需求拆解

1. 提供 `aclnnFusedExponentialGetWorkspaceSize` 和 `aclnnFusedExponential` 两段式接口。
2. 在 UB 中完成中间计算，消除 GM bool mask。
3. 按数据规模和平台资源分核分块，正确处理尾块及原地写回。
4. 在 910B3 完成精度、性能和内存自验，并提供 A3 适配。

# 3 详细设计

## 3.1 算子分析

计算公式：

```text
epsilon = finfo(u.dtype).eps / 2
out = -log(min(1-u, 1-epsilon)) / lambd
```

例如 `u=0.5, lambd=2`，输出约为 `0.34657359`。
epsilon 分别为 FLOAT16 的 2^-11、BFLOAT16 的 2^-8、FLOAT32 的 2^-24。
BFLOAT16 按公式定义及任务自验包 golden 取值。

## 3.2 Host 侧设计

校验指针、dtype、shape、rank、格式及率参数；非法输入返回错误。
非连续输入通过 Contiguous 转为连续数据，非连续输出通过 ViewCopy 写回。
根据元素数、数据类型、UB 容量和 AIV 核数计算每核区间及 tile 大小。
核间按 512 元素对齐，tile 按 64 元素对齐，尾块记录实际长度。
lambda 的缩放系数在 Host 计算；极端有限正值使用双系数处理，正无穷使用零填充路径。

## 3.3 Kernel 侧设计

采用 Init、CopyIn、Compute、CopyOut 结构，使用双缓冲衔接搬运和计算。
FLOAT16、BFLOAT16 先转 FLOAT32，依次执行 1-u、Mins 封顶、Ln 和缩放，最后收窄输出。
各核处理互不重叠的连续区间，DataCopyPad 按实际字节数处理尾块。
完全原地调用时先读入 UB，再写回同一区间；不使用原子更新或跨核归约。

连续融合 kernel 不申请 GM 中间张量，workspace 请求为 0。
CANN 9.1.0 非空连续 ACLNN 调用实际返回固定 512B 框架对齐空间，kernel 不使用该空间。
空张量返回 0，非连续布局转换另需临时空间。调用方按接口实际返回值分配。

## 3.4 支持硬件

| 硬件 | 编译目标 | 当前验证 |
| --- | --- | --- |
| A2 | ascend910b | 910B3 真机自验 |
| A3 | ascend910_93 | 完整包编译和安装，尚未真机运行 |

CANN 9.1.0 及以上，torch、torch_npu 2.7.1 及以上。
非连续输出依赖 ViewCopy，产品提交同时补齐其 A3 注册。

## 3.5 算子约束限制

输入值域由调用方保证，不支持广播或不同视图的部分重叠。
lambda 为正无穷时输出正零；有限正值的结果按输出 dtype 范围溢出或下溢。
u=0 时使用上限保护；接近 1 的一侧保持对数变换，不额外钳制。

# 4 特性交叉分析

融合后处理与随机数生成分离，不改变随机种子和状态。
非连续张量使用布局转换，连续张量直接进入融合计算。

# 5 可维可测分析

## 5.1 测试方案

按任务自验包运行 1000 条精度、200 条性能及 12 条内存探针。
专项测试补充空张量、标量、尾块、原地、非连续输出和非法参数，并使用 mssanitizer 检查。
精度工具失败保留原始状态，并按任务书说明原因。

## 5.2 验收标准

| 项目 | 标准 | 来源 |
| --- | --- | --- |
| 精度 | CPU torch 链式 golden，匹配比例不低于 0.99，并检查最大绝对误差 | 任务书 §3.2 |
| 性能 | 同设备逐例拼接链耗时/融合耗时不小于 1 | 任务书 §3.3 |
| 内存 | 无 GM bool mask，记录输入、输出及实际 workspace，并说明框架空间 | 任务书 §3.4 |

910B3 专项 294 条通过；官方精度 996 条通过，4 条为 ATK 输入准备失败，已直接接口补测。
200 条连续性能无退化，中位加速约 5.64 倍。融合 kernel 插桩无告警，系统依赖告警独立归档。

## 5.3 兼容性分析

本算子为新增 ACLNN 接口，不修改现有指数分布算子和随机状态。
产品代码、自验报告和原始日志分别归档，本设计文档不替代正式验收结果。
