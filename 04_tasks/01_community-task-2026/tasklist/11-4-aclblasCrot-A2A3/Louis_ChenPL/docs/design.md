# 需求背景

## 需求来源

2026 年 11 月 CANN 社区任务要求为 Atlas A2/A3 增加单精度复数向量 Givens 平面旋转。
复用 `include/cann_ops_blas.h` 中已有的 `aclblasCrot` 公共接口。

## 背景介绍

`aclblasCrot` 原地旋转两个 complex64 向量。旋转系数 c 为 float，s 为 complex64，
两者各自支持 Host 和 Device 指针。调用方通过 handle 绑定 stream。

# 需求分析

## 需求描述

将原始 x、y 按有符号步长配对，使用 Ascend C 在设备上计算旋转并写回原地址。
A2/A3 使用 arch22 参数契约，包括空句柄优先、零长度快速返回和步长溢出检查。

## 需求拆解

1. 在 Host 侧按规定顺序校验参数，独立识别 c、s 的内存位置，并根据向量长度选取向量核数。
2. 对连续向量在 UB 内做向量化运算，对跨步向量使用逐元素寻址。
3. 使用 CSV 和 GTest 覆盖参数边界、正负步长、标量位置、对齐偏移、随机输入与非有限值。
4. 使用 CANN 9.1.0 和 `msprof op` 验证单 kernel 性能。

# 详细设计

## 算子分析

### 数学公式

令 i 为从零开始的逻辑下标。正步长使用物理下标 `i * inc`，负步长使用
`(n - 1 - i) * abs(inc)`。设 X 和 Y 为一对旋转前的复数。

```text
X' = c * X + s * Y
Y' = c * Y - conj(s) * X
```

### 支持数据类型与形状

x、y 为实虚交织的 complex64 一维向量，逻辑长度 n。每个物理向量至少覆盖
`1 + (n - 1) * abs(inc)` 个复数元素。Host/Device 标量 c、s 分别占 4、8 字节。

## 算子实现

### Host 侧设计

校验顺序为 handle、负 n、零 n、步长与指针。对 n > 0，拒绝零步长、INT32_MIN
以及跨度超过 INT32_MAX 的参数。跨度在 int64 中计算。

Host 标量的值随启动参数传入，Device 标量以原指针传入，由 kernel 在绑定 stream 上读取。
启动参数按值下发，算子无需分配 GM tiling 缓冲或 workspace。每 4 个复数作为一个 32 字节逻辑块，
逻辑块在向量核间均分，末尾不足 4 个复数的部分按实际长度处理。

### Kernel 侧设计

- `incx = incy = 1` 时，每核以最多 2,304 个复数为一个 tile。两个 UB 输入输出缓冲组交替使用，
  提前读取下一块，允许搬运与向量计算重叠。通过 UB 中的交换索引获取相邻虚实分量，再用交替符号和乘加计算
  s × Y 与 −conj(s) × X。两组乘积使用原始 X、Y，尾块仅搬运有效字节。用向量 Axpy 合并两级乘加，并使用独立的双缓冲写回输出。
- 非单位步长时，每核分批按逻辑下标读取一对复数。输出通过每元素独立的 UB 对齐槽回写，
  因而保留步长间隙。标量路径显式保留每步 FP32 舍入，覆盖极端系数的抵消场景。
- x 和 y 指向同一基址且步长不同时，由单核按逻辑下标串行读写，后续迭代读取已写回的值。

## 支持硬件

| 产品 | 编译目标 |
| --- | --- |
| Atlas 800T A2 910B3 | `ascend910b3` |
| Atlas 800T A3 | `ascend910_93` |

## 算子约束限制

n = 0 时调用成功且不读写向量。n < 0 返回非法参数。不同基址的向量缓冲区不得部分重叠。
调用方在读取设备结果前同步 handle 绑定的 stream。

# 可维可测分析

## 精度标准与性能标准

| 验收标准 | 描述 | 标准来源 |
| --- | --- | --- |
| 精度 | 按 FP32 标准独立比较 x、y 的实部与虚部。atol 和 rtol 均为 2^-13，有限值匹配率至少 0.99，同时满足绝对误差上限和非有限值规则。 | 任务书 §3.2 |
| 性能 | 在 Atlas 800T A2 910B3 上用 msprof op 预热 5 次，每用例对至少 10 条有效 kernel 时长取平均，平均时长至多为 A100 基线的 1.25 倍。 | 任务书 §3.3 |
| 内存 | 无验收阈值。算子无 GM workspace，记录测试数据及实际 HBM 余量。 | 任务书 §3.4 |

## 兼容性分析

A2/A3 与 Ascend 950PR 共用公共签名。A2/A3 对负 n、零步长和 INT32_MIN 的返回码见
[rot 算子说明](../../blas/rot/README.md#aclblascrot)。

## 910B3 优化验证

代表用例 TC_PF_1078 的向量流水线忙碌比例中位数约 93%。合并向量乘加后，在同一张 910B3 上与 4608 分块基线对照，原先未达标的 37 项全部达标，耗时降幅中位数 11.1%。全量性能 200/200 达标，最低 GPU/NPU 耗时比 0.828；精度 1985/1985 通过。
