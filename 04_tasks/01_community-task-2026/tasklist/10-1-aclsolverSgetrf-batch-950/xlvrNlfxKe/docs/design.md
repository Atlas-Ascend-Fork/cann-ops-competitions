提供 Sgetrf、Sgetri、SgetriBatched、SmatinvBatched 及两工作区查询。

# 详细设计（required）

## 算子分析

### 数学公式

LU按顺序回放主元行交换满足 `P_apply * A = L * U`，L单位对角。
已有LU求逆为 `A^-1 = U^-1 * L^-1 * P_apply`，通过逆序列交换实现右侧置换。
原始批量求逆先做部分选主元LU，再复用求逆阶段。

对于小行数宽矩阵，令 `A=[A0 A1]`，先分解方块A0，然后并行做 `U1=L^-1 * P_apply * A1`。
不需要对右侧每列重复提交面板搬运。

### 支持数据类型与形状

FP32有限实数，范围见需求表及四个API文档。任务GPU输入不包含NaN/Inf契约。
指针和容量校验使用实际分配属性；内层批量地址在Device读取。

## 算子实现

### 3.2.1 host侧设计

1. 检查handle与创建context、尺寸、ld、外层Device属性、分配容量和外层重叠。
2. 计算查询元素数；验证调用者工作区，按问题规模选择向量、分块或批量路径。
3. 同步错误与提交错误返回aclsolverStatus_t；有效Device info在调用者stream内写入。
4. 小矩阵批量不需要Host解引用指针数组；大批量内部工作区按不超过512MiB的矩阵组调度。
5. handle内部缓存按stream区分；使用事件保护在途工作区，销毁时等待其完成。

### 3.2.2 kernel侧设计

| 路径 | 并行与运算 |
|---|---|
| 小秩LU | 向量面板、部分选主元、行交换、三角求解和rank更新 |
| 分块LU | 大秩或m>64且n≥4m走外层64/内层8；行映射数≤64时外层搬运宽64，否则32 |
| 小行数宽LU | 左方块分解，64列为一组并行主元与前代；2/4行使用8元素UB pitch |
| 128行宽LU | 成熟方块LU，基础向量API按64列并行前代，避免超长VF路径 |
| 单矩阵1至4阶逆 | 按U逆/去L/逆列主元计算，小阶每核私有UB计算后写所属列 |
| 单矩阵5至32阶逆 | 对齐LU副本和Device指针适配，共享批量三角逆，单batch直接写回；查询大小不变 |
| 单矩阵33至128阶逆 | 并行列点积求解，非对齐原布局单核最终写回，错误保留输入 |
| 单矩阵大逆 | 32阶对角块补偿求逆，递归合并三角逆，Cube乘积和最终列置换 |
| N2批量 | 融合的直接算式、受控舍入及对角商补偿 |
| N4批量 | 16向量寄存器保留矩阵；整数列置换直接散写输出 |
| N8批量 | 行打包8矩阵，8列寄存器；限制向量调度与VF融合以控制寄存器溢出 |
| N16批量 | 行打包4矩阵，4KiB UB tile按列保存中间结果 |
| 原始N3至N5 | 主元分阶段；TwoProd/TwoSum补偿R=I-XA，X←X+RX；中小批量均衡核负载 |
| 原始N10至N32 | 按列LU；10至17阶上部点积保留补偿，18至32阶采用FMA并校正倒数 |
| N11至N32求逆 | 按阶数及分组特化，保持U逆、去除L和逆序列置换的计算顺序 |
| 原始高阶调度 | N19/N20保留兼容调度；其余高阶独立编译，模板常量选择行块，限制活跃寄存器 |
| 中阶大批量33-128 | 按列U逆再去除L，UB tile保存列；系数广播；64行上下段交错，跳过高段结构零 |
| 其他小批量 | 组内向量化LU/三角逆，掩码覆盖尾批；非连续指针走通用路径 |

Cube显式关闭HF32，生产编译保留-fno-fast-math/-ffp-contract=off。
VF寄存器Gather使用有效索引；无效批量主元与别名先屏蔽，错误状态独立写回。

### 资源与同步

设备实际28AIC/56AIV、UB253952B，不从产品名称推定容量。
N8组768、N16组216；对应UB预算低于实际容量，N16包含4KiB tile。
N8采用默认6144B VF栈，已验证候选编译资源报告为2048B；诊断用扩栈产物没有运行或交付。
中阶大批量独立编译，保持正常向量调度；单段10VReg/双段13VReg，0B栈；batch≥4096启用。
MTE2/V/S/MTE3用显式事件与局部屏障保护各缓冲区，原始N3至N5残差在覆盖输入stage前完成。
原始N10至N13在4096≤batch≤56×96时，可按实际56AIV采用80/96单轮分组。
13阶组96的已分配UB与默认VF栈预算合计238976B，小于253952B；边界和内存检查须实测。
原始17至32阶输入stage在转置后复用为逆矩阵，LU存储在求逆结束后复用为输出pack。
紧密布局按n*n对齐到8元素，独立padding走通用行列搬运。compact22至27阶group40，28至30阶group32，
31/32阶group16；非紧密29至32阶group24。其他分组与单轮规则以冻结源码为准。
27阶compact/group40的已分配UB与默认6144B VF栈预算合计252032B，小于253952B；
第54版曾进行随机输入内存诊断；最终74版的额外mssanitizer检查报告GM告警，
50项未完成，不宣称内存检查通过。任务书3.4明确“内存不做要求”。
高阶raw/prepared路径保持整数info，避免两次无用转换；group<=64时每核缓存LU lane种子与输出pack种子。
两组64个uint32占现有outputOffsets[0..127]，无需新增分配；Crout/三角逆只读第一组，pack只读第二组。
其他分组和已有LU路径保留原索引生成；原始18阶单轮group80的回退路径也保留。
高阶独立TU只清零逆矩阵严格下三角；U逆逐列生成所有上三角和对角元，再被后续步骤读取。
这些调整不改变FP32点积、乘加、倒数及置换计算顺序。候选63#192输入/输出字节与56版一致，
最终74版的完整精度与性能验证结果见本设计“可维可测分析”；未以源码相同代替完整实测。
新高阶TU使用默认调度，低阶兼容TU维持关闭向量misched/VF融合；未增大默认VF栈。
单逆5至32阶保留两份n*align8(n)浮点工作区查询。第一半保存LU副本，第二半在偏移0/32字节
放置输入/输出指针数组，总共64字节；n>=5时第二半至少160字节，满足容量。
指针只在Device产生，依调用者stream先复制LU，再写指针，再做单batch三角逆；输出直接写原A。
不增加Host同步；新路径已对保存的N16无主元输入重放并检查15次kernel内存，完整回归状态另记。
调用者在读取结果、释放矩阵/指针数组/工作区前同步绑定stream。

## 算子约束限制

- 内存消耗按真实batch/ld计算；不以任务表中的4GiB示例限制排除给定大batch。
- 查询和尺寸使用int，所有乘积先扩到size_t，超查询整数范围返回非法参数。
- 输入/输出独立的批量接口不允许同矩阵重叠；无效info地址不写入。
- Device内层任意伪造地址的完整可访问性与跨矩阵别名检测仍按测试证据记录，未验证不宣称支持。

## 兼容性分析

实数旧Host原型按本任务升级为aclsolverStatus_t、Device数据和已有LU求逆，调用者需要迁移。
头文件声明为C链接，参数位置不含handle，错误值语义以任务书为准。
设计评审、代码CI、CLA、用户提交和官方验收是独立流程，开发者自验不代替这些状态。

### 无主元大阶数的精度路径

129至4096阶无主元单逆采用独立RHS逐列求解。每个内积先用FMA分解乘积的高/低部分，
再用TwoSum保留求和误差，并把低部分加入补偿项；整个NPU路径仅使用FP32。
先在工作区复制完整LU，各核只读该副本并写对齐输出半区，最后单核按原leading dimension写回。
零主元先扫描并记录第一个info，错误时保留原LU。工作区查询沿用现有较大的大矩阵查询，不额外增加。
UB固定预算203040B含默认栈，支持最大4096；对角DMA按2048块分段，满足9.1最大4095块约束。
70版N255保存输入5次误差比0.0095071626（原上限1.6045489552）；全部83项及15条受影响主任务精度/性能通过。
72版修正最大阶搬运分段；74版已进行同库全量回归，上述712项与补充验证范围为最终开发者自验结果。
