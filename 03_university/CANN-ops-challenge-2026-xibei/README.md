# 🏆 CANN 挑战赛（西北赛区）

> **大赛简介**
> CANN 挑战赛是华为算法挑战赛的子赛道。西北赛区主要面向陕西、甘肃、河南、山西、新疆、青海、宁夏地区高校在校学生。大赛围绕昇腾 AI 算子开发、功能实现与性能优化设置竞赛任务，并提供配套学习资料和在线实践环境，帮助参赛选手了解算子开发流程，提升编程实践和性能优化能力。

## ⚖️ 赛事规则

* 🎯 **参赛对象要求**：主要面向陕西、甘肃、河南、山西、新疆、青海、宁夏地区高校在校学生。
* 🗺️ **赛区匹配规则**：组委会根据参赛选手所在高校的省份匹配赛区，“所在省份”是指高校所属省份，不是户籍所在地或当前居住地。
* 📌 **报名要求**：已通过统一预报名入口完成预报名的选手，无需重复报名。参赛选手须按赛事通知完成赛区确认、组队，方可有效参赛。
* 📝 **参赛答题要求**：参赛选手需要根据赛题赛规要求，在指定时间内完成报名、赛区选择、组队、作品提交，方为有效参赛。(每天最大提交次数为50次，取比赛期间最后一次提交的成绩作为最终成绩)。
* 🤝 **组队要求**：同一支队伍的成员须属于同一赛区，不支持跨赛区组队；同一赛区内，符合报名条件的学生可以跨学校组队。
* 🛡️ **公平参赛**：参赛队伍应独立完成作品并遵守赛事规则。作品查验、违规处理及成绩认定方式，正式赛事规则：https://cannjudge.cn/public/op_challenge_jingdong_prelim/scoring-rules
* 📌 **CANNLab算力申请要求**：西北地域参赛队伍，仅允许队长申请算力资源，申请算力资源后不能更换团队名称、队伍成员，仅允许使用队长账号登录。请参赛者务必在申请算力资源前完成队伍组建（<span style="color:#e60000;">请填写申请理由并附上一条答题记录</span>）。
* ⚔️ **比赛机制**：
    1.  比赛分初赛和决赛两个赛段，每个赛段包含“在线训练”和“正式比赛”两个阶段。在线训练阶段提交的作品仅用于代码调试参考，不计入评奖参考。
    2.  正式比赛中，各参赛队伍把最优成绩作为本团队最终成绩进行排名，**请各位选手做好版本管理**。
     3.  组委会提醒全体参赛选手，本赛事要求核心计算在<span style="color:#e60000;">昇腾 NPU 上通过 AscendC 算子实现完成</span>,任何将计算转移至 Host CPU、通过空 kernel 占位绕过 NPU 计算要求的行为，均构成违规，<span style="color:#e60000;">将取消当前提交成绩</span>。
    4. 赛事奖金由华为技术有限公司承担

## 📚 学习与备赛

没有算子开发基础也可以报名参赛。建议参赛选手通过 **CANN 学习中心仓**，提前学习 CANN、昇腾 AI 及算子开发相关知识。

CANN 学习中心仓支持在线互动运行、边学边练，提供教程、示例与优化方案，一站式助力昇腾开发者快速上手。

* [进入 CANN 学习中心仓](https://gitcode.com/cann/cann-learning-hub)

赛题发布后，建议结合西北赛区发布的赛事题目和学习中心仓中的教程、示例开展练习，先保证功能正确，再逐步进行性能优化。
